# Projeto: memalloc

Projeto integrador do **Bloco 0 — Fundição do Ferro**.

## Sobre

Alocador de memória simplificado, implementado do zero em C. Gerencia
uma região de memória fornecida, com controle manual de blocos livres
e ocupados. O objetivo é entender como o `malloc` funciona por baixo.

## Conceitos aplicados

- Ponteiros e aritmética de ponteiros
- Structs e `typedef`
- `void *` e casts explícitos
- `malloc` / `free`
- Lista encadeada aplicada a metadados
- Layout de memória e alinhamento
